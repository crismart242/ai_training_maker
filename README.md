# SAP AI Learning Skills

A collection of reusable AI agent skills created by the SAP Learning team,
designed to help SAP employees learn and apply AI concepts in their daily work.

Skills in this repository are compatible with [Joule Work Desktop](https://skills.cloud.sap)
and any agent that supports the [Agent Skills](https://agentskills.io) open standard
(Claude Code, GitHub Copilot, Cursor, and more).

---

## Installation

### Via Joule Work Desktop
Browse and install skills directly from [skills.cloud.sap](https://skills.cloud.sap).

### Via CLI
Install all skills:
```bash
npx skills add your-github-username/your-repo-name
```

## Repository Structure
skills/
└── skill-name/
    ├── SKILL.md        # Skill instructions and metadata
    ├── references/     # Supporting documentation (optional)
    ├── scripts/        # Helper scripts (optional)
    └── assets/         # Templates and static resources (optional)
